# The Kayile - Himalayan Luxury Retreat

A stunning showcase website for The Kayile, a luxury Himalayan retreat featuring:

- **Pinus wallichiana craftsmanship** - Handcrafted furniture and decor
- **Forest sanctuary** - Immersed in nature at 9,000 feet elevation
- **Chanchal Valley views** - Breathtaking panoramic mountain vistas
- **Luxury accommodations** - Premium rooms and suites
- **Modern amenities** - All the comforts of home in the mountains

## Features

- Responsive design optimized for all devices
- Interactive room showcase with detailed information
- Social sharing capabilities
- Contact and booking information
- Beautiful animations and transitions
- Dark/light theme support

## Technology Stack

- **Frontend**: React 18 with TypeScript
- **Styling**: Tailwind CSS with custom components
- **Build Tool**: Vite
- **UI Components**: Radix UI primitives
- **Icons**: Lucide React
- **Animations**: Framer Motion

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

4. Preview the production build:
   ```bash
   npm run preview
   ```

## Deployment

The project is configured for easy deployment to Vercel, Netlify, or any static hosting service.
